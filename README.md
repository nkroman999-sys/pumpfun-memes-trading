
# Pump.fun Meme Trading

Notes, watchlists, and practice code for meme tokens on Pump.fun.

## Purpose
- Track new meme tokens
- Keep personal notes
- Practice simple helper scripts

## Folder structure
- `notes/` — token notes
- `watchlist/` — tokens to watch
- `scripts/` — small helper scripts

## Getting started
1. Clone this repository
2. Add token name, contract address, and observations in `notes`
3. Do your own research before any trade

## Disclaimer
This project is for learning only.
Tokens on Pump.fun are extremely high risk.
This is not financial advice.
